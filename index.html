01 COMPLETED

AI Career & Job Matching Platform

A web-based platform that analyzes a resume against a job description using Natural Language Processing (NLP) and machine learning.

The platform produces a match score, identifies matched and missing skills, and provides skill-gap recommendations to help users understand their job readiness.

Built as a 15-day self-directed learning project with the goal of understanding every layer of the system deeply enough to explain the implementation in a technical interview.

Key Features:
  • Resume PDF upload and text extraction
  • Job description text extraction
  • NLP preprocessing using tokenization, stopword removal and lemmatization
  • Dictionary-based skill extraction across Programming, Data, Machine Learning, Web and Cloud/DevOps categories
  • TF-IDF and cosine similarity based text matching
  • Semantic similarity using Sentence Transformers
  • Weighted final match score combining skill matching and text similarity
  • Matched skills and missing skills breakdown
  • Skill-gap recommendations with plain-language explanations
  • Job application tracker with status pipeline
  • Dashboard with database-driven statistics and Chart.js visualization
Tech Stack: Python Flask SQLite SQLAlchemy NLP NLTK Scikit-learn TF-IDF Sentence Transformers PyPDF HTML5 CSS3 JavaScript Chart.js
